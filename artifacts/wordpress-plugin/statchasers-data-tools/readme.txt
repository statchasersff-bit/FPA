Frontend display for StatChasers Fantasy Points Allowed data, served from a snapshot bundled inside the plugin.

== Description ==

This private plugin renders the StatChasers Fantasy Points Allowed table on your
WordPress site. The FPA snapshot ships inside the plugin (data/fpa-data.json);
WordPress only reads and displays it. Nothing is computed or fetched at runtime,
and there is no push/sync endpoint.

To update the numbers: regenerate or edit data/fpa-data.json in the repo, rebuild
the plugin zip, and re-upload it in WordPress (Plugins → Add New → Upload, or via
your usual deploy). The display picks up the new data on activation.

= Features =

* Admin menu "StatChasers Data" with a read-only "Fantasy Points Allowed" dashboard.
* Status panel: current data mode, snapshot timestamp, source season, current
  season, number of teams, and whether data is bundled / preseason.
* Public read-only endpoint that serves the bundled data.
* `[statchasers_fpa]` shortcode that renders a branded, mobile-friendly table.
* Settings: default season, default scoring format, cache duration.

== REST Endpoints ==

* GET /wp-json/statchasers/v1/fpa?format=ppr&view=adjusted
  Public, read-only. Returns the bundled snapshot for the requested combo.

== Updating the data ==

The snapshot is generated by the repo's `scripts/refresh-fpa.ts`, which fetches
nflverse weekly stats, computes FPA/aFPA for all six format/view combos, and
writes the result to the plugin's data/fpa-data.json:

1. Run `pnpm run refresh:fpa` in the repo (writes data/fpa-data.json directly).
   Or hand-edit data/fpa-data.json if you only need to tweak numbers.
2. Rebuild the plugin zip.
3. Re-upload the plugin in WordPress.

No external services, secrets, or scheduled jobs are involved.
